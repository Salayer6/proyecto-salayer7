## 🏗️ Metodología de Planificación y Control de Proyectos

La gestión rigurosa de proyectos articula tres ingredientes esenciales, alineados con los estándares del **Project Management Institute (PMI)** y la práctica ingenieril:

1. **Recurso:** Gestión eficiente de mano de obra, materiales, maquinaria, equipos y financiamiento.
2. **Operación:** Ejecución física en faena, flujos de trabajo en terreno y coordinación de subcontratistas.
3. **Control / Estrategia:** Monitoreo del desempeño contra presupuesto y cronograma (seguimiento de hitos), mitigación de riesgos y aseguramiento de calidad.

### Niveles de Programación con Oracle Primavera P6:

```
[ Nivel 1: Hitos Contractuales ] ──▶ [ Nivel 2: WBS / EDT Gerencial ] ──▶ [ Nivel 3: Cronograma CPM de Actividades ]
                                                                                   │
                                                                                   ▼
                                                             [ Nivel 4: Last Planner System (Look-Ahead) ]
```

- **I. Hitos:** Fechas contractuales y sincronización con dependencias externas.
- **II. Work Breakdown Structure (WBS / EDT):** Estructura desglosada que organiza el alcance total para toma de decisiones directivas.
- **III. Cronograma de Control (CPM):** Cálculo del Método de Ruta Crítica y análisis detallado de actividades (el plan base comprometido).

![Operación de Oracle Primavera P6](https://github.com/Salayer6/proyecto-salayer7/blob/main/Video%20P6%201.gif)

- **IV. Last Planner System (Lean Construction):** Planificación semanal y de contingencias mediante planillas *Look-Ahead* en Excel, gestionadas para coordinar cuadrillas, resolver restricciones y registrar avance real en faena.
